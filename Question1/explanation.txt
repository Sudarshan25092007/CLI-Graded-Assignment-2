1. mkdir
Created the required directories to organize submissions, backups, outputs, and screenshots.

2. echo
Created sample assignment files for different students.

3. cp
Copied one student's assignment to another to simulate a duplicate submission.

4. find + md5sum
Calculated file hashes to detect duplicate files based on their content.

5. chmod +x
Made the shell script executable.

6. ./backup_submissions.sh
Executed the script to process submissions, detect duplicates, create backups, and generate reports.

7. cat report.txt
Displayed the summary report generated by the script.

8. ls backup
Verified that only unique files were backed up.

9. cat errors.log
Checked for any error messages generated during execution.
